# AI 포트폴리오 점검 문서 정량 데이터 통합 명세

기준 버전: 1.13.0

## 목적

외부 ChatGPT에서 포트폴리오를 점검할 때 필요한 입력을 플랜별 문서 하나로 제공한다.
문서는 선택한 플랜의 실제 보유 상태와 목표 비중, 정량 레짐 근거, 사용자 의사결정 지침을
하나의 시점 일관된 맥락으로 묶는다. 레짐 화면의 별도 Markdown·JSON 다운로드는 제거한다.

## 문서 순서

1. 생성 시각, 플랜과 포트폴리오 식별 정보
2. 실제 자산과 그룹별 현재·목표 비중
3. 플랜에 연결되지 않은 보유 자산
4. `Meowney 정량 레짐 데이터`
5. 사용자가 저장한 플랜 전략 프롬프트 또는 기본 의사결정 프롬프트

정량 근거는 사용자 지침보다 먼저 배치한다. 외부 모델이 데이터와 사용자 요구를 구분하면서도
같은 문맥에서 해석할 수 있도록 하기 위함이다.

## 정량 데이터 계약

### 공통 메타데이터

- 평가 시각, 최신 관측일 범위와 마지막 수집 시각
- 레짐 규칙 버전과 데이터 coverage
- 상세점검 필요도, 확정·후보 자동 레짐
- 직전 공식 Snapshot 이후 핵심 변화와 활성 임계 신호

### 거시·시장

- 시장·환율·원자재: KOSPI, S&P 500, Nasdaq, VIX, USD/KRW, DXY, WTI, 구리, 금, 은, 금은비
- 미국 성장·고용: GDP, 실업률, 비농업 고용, 신규실업수당, 소매판매, 산업생산
- 한국 거시 보조: GDP, 수출, 산업생산
- 물가: CPI, Core CPI, PCE, Core PCE, PPI, 임금
- 금리: 기준금리, 3M·2Y·10Y·30Y, 10Y·30Y 실질금리, BEI, 10Y-3M, 2Y-10Y, 기간 프리미엄
- 유동성·신용: HY·IG OAS, NFCI, Fed 자산, 은행 준비금, 역레포

각 행에는 가능한 범위에서 현재값, 판정 창 변화값, 상태와 사유, 관측일, 출처를 기록한다.

### 금융 전달경로

- 정책금리와 실질 정책금리 제약
- 10Y·30Y 명목/실질금리, 20·63관측일 변화와 장기 듀레이션 부담
- 10Y-3M 주축, 2Y-10Y 확인축과 침체 선행 판정
- HY·IG OAS와 NFCI 신용 환경

### AI 인프라 투자 가설

- Microsoft, Alphabet, Meta, Amazon의 공시 CAPEX와 전년비
- 공개 DRAM·NAND 가격 표본
- DRAM 칩·MCP·DRAM 모듈 수출액, 단위중량당 수출액과 단기/구조 변화
- KOSIS 반도체 생산·출하·재고와 재고/출하 비율
- 삼성전자·SK하이닉스 공시 매출·영업이익·재고·CAPEX
- EIA 전력 판매·발전·설비용량

직접 HBM 가격처럼 현재 확보하지 못한 데이터는 추정값으로 채우지 않고 데이터 공백으로 명시한다.

## 출력 제한

- 차트 전체 시계열, 모든 raw observation, 공식 Snapshot 원문과 내부 디버그 필드는 넣지 않는다.
- API 키, 인증 헤더, 로컬 경로와 내부 오류 상세를 출력하지 않는다.
- 데이터가 없으면 해당 섹션을 생략하거나 공백으로 표시하며 다른 지표로 임의 대체하지 않는다.
- 문서 생성은 외부 API 강제 새로고침, 공식 Snapshot 생성, 상세점검 확인 상태 변경을 일으키지 않는다.
- 정량 블록은 50,000자 미만을 유지한다. 전체 문서 크기는 보유 자산과 사용자 프롬프트 길이에 따라 달라질 수 있다.

## API와 UI

- 유지: `GET /api/v1/rebalance/plans/{plan_id}/decision-prompt`
- 제거: `GET /api/v1/regime/export`
- 플랜 화면 CTA: `AI 포트폴리오 점검 문서`
- 레짐 화면에는 별도 다운로드 CTA를 두지 않는다.

## 검증

- 정량 블록이 포트폴리오 상세 뒤, 사용자 지침 앞에 위치하는지 검사한다.
- 관측일과 출처, 주요 파생값, 데이터 공백이 출력되는지 검사한다.
- 전체 시계열 및 sentinel 데이터가 섞이지 않는지와 출력 크기 상한을 검사한다.
- 희소한 선택 데이터에서도 문서 생성이 실패하지 않는지 검사한다.
- 레짐 Export 라우트와 다운로드 버튼이 다시 노출되지 않는지 검사한다.
