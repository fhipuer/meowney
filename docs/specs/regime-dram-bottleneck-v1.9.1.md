# DRAM 중심 반도체 판정 명세 v1.9.1

## 목적

AI 슈퍼사이클 전체는 하이퍼스케일러 CAPEX, 반도체, 전력 인프라를 서로 다른
관측축으로 유지한다. 반도체 내부에서는 DRAM을 주 판정축으로 두고 NAND,
한국 반도체 완제품 재고와 국내 기업 공시는 확인·보조축으로 사용한다.

외부 정성 자료는 규칙을 검증하는 근거이며 런타임 입력으로 하드코딩하지 않는다.
자동 판정은 캐시에 저장된 구조화 데이터만으로 동일 입력에 같은 결과를 낸다.

## 데이터 위계

1. **주축**: TrendForce 공개 DDR5 Contract 가격 표본
2. **수요 확인**: 관세청 한국 DRAM 수출액의 3개월 평균 YoY와 지속성
3. **기업 확인**: OpenDART 삼성전자·SK하이닉스 매출·수익성·재고
4. **광의 보조**: KOSIS C261 반도체 제조업 완제품 생산·출하·재고
5. **별도 보조**: NAND 공개 가격 표본

공개 DDR5 표본은 HBM 또는 Server DRAM 계약가격을 직접 측정하지 않으므로
`DRAM 수급 핵심축`의 신뢰도는 해당 데이터 연결 전까지 `부분`으로 표시한다.

## DRAM 수급 핵심축

- DDR5 가격 상승과 DRAM 수출 또는 국내 기업 확장이 함께 확인되면 `타이트 신호`.
- 가격만 상승하면 `가격 상승 확인`.
- 수출·기업은 강하지만 가격 확인이 없으면 `수요 강세·가격 대기`.
- 가격 하락과 수출 또는 기업 약화가 함께 나타나면 `병목 완화 경계`.
- KOSIS 보조축 하나만으로 위 DRAM 판정을 반전하지 않는다.
- DRAM 주축이 강해도 KOSIS와 기업 두 보조축이 동시에 악화되면 반도체 종합은
  `경계`로 낮춘다.

## KOSIS 완제품 재고 판정

3개월 변화는 연율화하지 않는다. `재고 부담`에는 다음 조건을 모두 요구한다.

1. 최소 36개월 이력
2. 완제품 재고 수준 70백분위 이상
3. 계절조정 재고/출하 비율 70백분위 이상
4. 재고 YoY와 출하 YoY 격차가 2개월 연속 +10%p 이상
5. 재고/출하 비율의 3개월 상승률 +5% 이상 또는 최신 격차 +15%p 이상

재고가 3개월간 8% 이상 반등했더라도 재고 수준이나 재고/출하 비율이
50백분위 미만이고 최신 YoY 격차가 +10%p 미만이면 `재고 반등 관찰`이다.
이는 DRAM·HBM 제품별 재고 부족 또는 과잉을 직접 뜻하지 않는다.

## 회귀 기준

2026년 6월 캐시 입력에서 재고 YoY 약 +3.0%, 출하 YoY 약 +3.1%, 계절조정
재고 3개월 변화 약 +9.8%, 재고 수준 약 20백분위, 재고/출하 비율 약
13백분위인 경우 결과는 `재고 반등 관찰`이어야 하며 `재고 부담`이면 안 된다.

## 남은 데이터 공백

- HBM 세대별 계약·출하·공급충족률
- Server DRAM 계약가격, RDIMM 출하 및 공급충족률
- 공급사 DRAM bit shipment·bit growth·재고일수

이 데이터가 연결되면 공개 DDR5 모듈 가격을 보조 가격축으로 낮추고 HBM·Server
DRAM 직접 수급을 주축으로 승격한다.
