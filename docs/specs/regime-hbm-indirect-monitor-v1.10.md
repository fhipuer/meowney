# HBM·서버 DRAM 간접계측 명세 v1.10.1

> DRAM 신고중량을 출하량으로 사용하던 아래 수출 분해 규칙은 v1.12에서 폐기되었다.
> 현재 규칙은 `regime-long-end-and-dram-export-v1.12.md`를 따른다.

## 목적

무료로 안정적으로 수집 가능한 HBM 계약가격·공급충족률이 없는 상태에서, 서로 다른
공개 원자료가 같은 수급 방향을 가리키는지 결정론적으로 확인한다. 결과는 DRAM 주축의
확인 신호이며 `HBM 직접 데이터`로 표시하거나 자동 거시 레짐을 단독 변경하지 않는다.

## 입력 위계

1. **서버 가격 방향**: TrendForce 공개 `DDR5 RDIMM 32GB 4800/5600` 모듈 표본
2. **수출 구조**: 관세청 DRAM 칩·MCP·DRAM 모듈 수출액, 신고중량과 `수출액/중량`
3. **공급사 상대 재고부담 맥락**: SK하이닉스 분기말 재고 ÷ 같은 분기 매출의 전년동기 변화
4. **보조 맥락**: 삼성전자 전사 재고/매출 비율, 공개 DDR5 계약가격, KOSIS 완제품 재고

SK하이닉스는 메모리 사업 순도가 높아 상대 재고부담의 주 관측회사로 표시한다. 그러나
이 값은 같은 DART 매출·재고의 파생값이므로 독립 신호로 점수에 중복 반영하지 않는다.
삼성전자는 전사 연결 수치이므로 회사 내 자기 추세만 보조 맥락으로 표시한다.

## 파생값

### DRAM 수출 구조

- DRAM 칩 수출액을 주축으로 하고 MCP·DRAM 모듈 수출액을 후공정 확인축으로 사용한다.
- 최근 3개월의 전년동월 대비 평균과 최근 2개월 방향을 구조 신호로 사용한다.
- 최근 3개월 평균과 직전 3개월 평균의 변화는 단기 감속·재가속 보조값으로 분리한다.
- `단위중량당 수출액 = DRAM 수출액 USD / 신고중량 kg`은 가격·제품믹스 맥락이다.
- v1.10 당시의 `물량 주도 확장` 상태는 폐기하고 신고중량 감소만으로 상충 신호를
  생성하지 않는다.

`USD/kg`는 순수 가격이 아니다. HBM 등 고부가 제품 비중, 패키징과 신고 구성 변화가
함께 반영된다. 신고 중량 또한 DRAM bit 출하량을 대체하지 않는다.

### 공급사 매출 대비 재고

- `재고/매출 = 분기말 재고자산 / 해당 분기 매출 × 100`
- 계절성을 줄이기 위해 직전 분기가 아니라 전년동기와 비교한다.
- 비율 YoY가 -20% 이하이고 매출 YoY가 +10% 이상이면 `상대 재고부담 크게 완화`.
- 비율 YoY가 -5% 이하이고 매출이 증가하면 `상대 재고부담 완화`.
- 비율 YoY가 +20% 이상이며 재고 YoY가 매출 YoY보다 10%p 이상 높으면
  `상대 재고부담 크게 확대`.
- 재고 절대액이 증가해도 매출이 더 빠르게 늘어 비율이 낮아질 수 있다. 이 경우
  재고 부족이나 물리적 소진을 단정하지 않고 매출 대비 상대 부담 하락으로만 해석한다.
- 비율 YoY는 `(1+재고 YoY)/(1+매출 YoY)-1`의 재표현이다. 독립 정보가 아니며
  가격·제품믹스로 매출 분모가 급증해도 낮아질 수 있다.

## HBM·서버 DRAM 간접 판정

- RDIMM 상승 + 수출 구조 확장: `타이트 지속 신호`
- RDIMM 상승만 확인: `타이트 관찰`
- RDIMM 하락 + 수출 구조 약화: `병목 완화 경계`
- RDIMM 하락만 확인: `완화 관찰`
- RDIMM 유효기간 초과 또는 미수집: 수출 구조가 강해도 `판정 제한`

단순 점수 합산을 하지 않는다. 서버 가격 방향을 먼저 확인한 뒤 수출 구조가 확인 또는
반박하는 순차 규칙을 사용한다. 공급사 상대 재고부담은 DART 기업 확인과 같은
`source_family`의 설명용 맥락으로만 보존한다. 모든 결과의 신뢰도는 HBM 직접 데이터가
연결되기 전까지 `부분`이다.

## 2026년 8월 회귀 기준

현재 캐시와 같은 입력에서 DRAM 수출액 3개월 평균 YoY가 약 +421%, 신고 중량이
약 -10%, 단위중량당 수출액이 약 +484%, 서버 RDIMM 표기 변화율이 +1.29%,
SK하이닉스 재고/매출 비율 YoY가 약 -62%라면 다음을 만족해야 한다.

- 수출 구조: `단가·믹스 주도 확장`
- 간접계측: `타이트 지속 신호`
- 상충 신호: DRAM 수출중량 감소를 별도 표시
- DRAM 종합 주축: 공개 DDR5 가격 상승과 결합해 `타이트 신호`

## 화면 및 보존

- `현재`: RDIMM, 수출 단가·믹스, 수출중량, SK하이닉스 재고/매출을 한 카드에 표시.
- `메모리·반도체`: 수출액·중량·단위중량당 수출액 정규화 차트와 공급사 재고/매출
  분기 차트를 표시.
- 공식 Snapshot JSON, 이전 Snapshot 변화 감지, Markdown Export에 간접계측 상태와
  근거를 함께 보존한다.
