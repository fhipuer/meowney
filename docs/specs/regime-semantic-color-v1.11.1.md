# 투자 레짐 의미 색상 규칙 v1.11.1

## 목적

레짐 화면의 색은 숫자의 양수·음수가 아니라 현재 투자 가설에 대한 의미를 나타낸다.

- `positive`: 신선한 데이터와 판정 규칙이 가설 강화를 확인
- `caution`: 단일 축, 상충, 감속 또는 지속성 미확인
- `negative`: 복수 조건이나 임계 규칙이 가설 훼손을 확인
- `info`: 연결 상태, 방법론 또는 경제 방향과 무관한 정보
- `neutral`: 부호만으로 해석할 수 없는 원시값, 판정 미사용 값, 오래된 값

빨강은 음수를 뜻하지 않고 확인된 가설 훼손을 뜻한다. 차트 선은 데이터셋을 구분하는
범주형 색이며 의미 색상으로 사용하지 않는다.

## 적용 규칙

| 영역 | 의미색 적용 | 중립 유지 |
| --- | --- | --- |
| 성장·고용 | 실질 GDP·산업생산 변화, 실업률·실업수당 변화 | 명목 소매판매, 고용수준 원시 변화 |
| 물가·금리 | 합성 상태와 임계 판정 | 원시 물가율, 개별 금리 증감, 수익률곡선 단순 변화 |
| 신용·유동성 | HY·IG 스프레드 확대·축소 | Fed 자산, 준비금, RRP 단일 증감 |
| 시장 | 활성 충격 판정 | 지수·환율·원자재·금·은의 단순 수익률 |
| AI CAPEX | 기업별 증가는 보조 강화, 광범위 합성 상태 | 절대액·TTM; 단일 기업 감소는 관찰 |
| DRAM·NAND | 계약가격·RDIMM·NAND 주 표본의 확인된 방향 | 변동성 높은 Spot, Client SSD 보조 표본 |
| 기업 공시 | 매출 10% 이상·영업흑자·이익률 급락 없음, 상대 재고부담 변화 | 재고 절대액 YoY, 공급사 CAPEX YoY |
| 전력 | 총판매·상업용 판매의 합성 수요 상태 | 산업용 판매·발전량·설비용량 단일 증감 |

## 회귀 방지 원칙

1. 오래되거나 미수집인 값은 의미색을 제거한다.
2. 원시값과 합성 판정을 동일한 독립 신호로 중복 강조하지 않는다.
3. 간접 관측은 정보색으로 표시하고 경제적 경계색과 구분한다.
4. 새 판정 상태를 추가할 때 `regime-tone.ts`와 표 기반 테스트를 함께 갱신한다.
5. 현재·지표·기록 화면에서 같은 판정은 같은 의미색을 사용한다.
