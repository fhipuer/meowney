# 투자 레짐 데이터 소스 로드맵

기준 버전: 1.13.0

이 문서는 현재 연결 범위, 결정론적 판정에 쓰이는 역할과 다음 구현 후보를 구분한다.
미연결 자료를 임의 프록시로 채우거나 서로 다른 의미의 시계열로 재명명하지 않는다.

## 반도체·전력 판정 원칙

- 반도체 판정은 공개 DDR5 가격을 주축으로 하고 `서버 RDIMM 공개가격`,
  `관세청 DRAM 칩·MCP·모듈 수출액`, `SK하이닉스 매출 대비 재고`를 HBM·서버 DRAM
  간접 확인축으로 묶으며 `KOSIS 완제품 재고`는 광의 보조축으로 사용한다.
  KOSIS 단독 신호는 DRAM 주축을 반전하지 않는다.
- 수출은 전년동월 대비 최근 3개월 평균과 2개월 지속성을 구조 신호로, 최근 3개월 평균과
  직전 3개월 평균의 변화를 단기 속도 신호로 사용한다. 신고중량은 포장·패키징을 포함한
  순중량이므로 bit 출하량으로 취급하거나 감소만으로 부정 판정을 만들지 않는다. KOSIS는 원지수
  전년동월 대비, 계절조정 완제품 재고·재고/출하 비율의 역사적 백분위와 비연율화
  3개월 변화를 함께 사용한다.
- OpenDART 누적 손익·현금흐름은 직전 누적값을 차감해 분기로 환산하고, 비교 지표는
  매출·영업이익·재고가 공통으로 존재하는 같은 결산일에 맞춘다.
- EIA 월간 전력은 계절성이 크므로 전년동월 대비 최근 3개월 평균으로 읽는다. 상업용
  판매는 데이터센터 전용 수요가 아니며 EIA만으로 계통 병목을 판정하지 않는다.
- 이 네 소스는 투자 가설의 보조 확인 자료다. 현재 미국 거시 4분면이나 자동 레짐을
  단독으로 변경하지 않으며 공식 Snapshot과 플랜별 AI 포트폴리오 점검 문서에는 당시 결과를 함께 보존한다.

## 캐시와 장애 처리

- 원자료는 `value / observationDate / fetchedAt / source`와 세부 차원을
  `regime_external_observations`에 저장한다.
- KOSIS·관세청·OpenDART는 정상 수집 후 20시간, 미 재무부 금리곡선은 8시간,
  EIA는 48시간 동안 캐시를 재사용한다.
  실패한 소스만 1시간 후 재시도하고 다른 소스의 성공 캐시는 유지한다.
- 일부 OpenDART 보고서만 실패하면 `partial`로 표시하고, 사용할 수 있는 공시와 이전
  정상 캐시는 계속 제공한다. 화면과 API의 피드 상태에서 마지막 성공 시각과 오류를 확인한다.

## 다음 연결 우선순위

### 1. Server DRAM·HBM·Enterprise SSD 직접 데이터

- 필요한 데이터: 계약가격, 출하·재고, bit 공급/수요, HBM 세대별 수급.
- 현재 상태: 무료 구조화 직접 API는 미연결이며, 기존 공개자료를 조합한
  `HBM·서버 DRAM 간접계측`만 제공한다.
- 서버 RDIMM은 모듈 공개가격, 관세청 `USD/kg`는 가격과 제품 믹스의 합성값,
  신고 중량은 bit 출하량이 아니다. 셋을 HBM 직접가격·공급충족률로 재명명하지 않는다.
- 유료 라이선스나 신뢰 가능한 공급자가 정해질 때 source registry와 이용조건을 먼저 검토한다.

### 2. 전력망 병목과 기업 수주

- 필요한 데이터: 지역별 데이터센터 부하, 계통 연결 대기, 변압기 리드타임,
  GE Vernova·Eaton·ABB·Schneider·Quanta의 orders/backlog.
- EIA 총수요·상업용 판매·설비용량과 별도 축으로 구현한다. 기업 공시 자동화는 회사별
  계정·단위·수주 정의를 검증한 뒤 진행한다.

### 3. 밸류에이션·이익 추정치

- 후보 데이터: 지수 forward PER, 기업 이익 추정치 revision.
- 무료 비공식 스크래핑은 안정성과 이용조건 문제가 있어 후순위다. 공급자를 선택하기 전
  자동 레짐 입력에 넣지 않고 출처·산식·point-in-time 제공 여부를 검증한다.

## 다음 API 발급 요청 시점

1.13.0 범위에 필요한 무료 키는 모두 연결되었다. 다음 작업에서는 HBM/Server DRAM 직접 데이터 또는
전력망 병목의 실제 공급자를 먼저 선정하며, 공급자와 라이선스가 확정되기 전에는 추가 키나
구독을 요청하지 않는다.
