# 투자 레짐 데이터 소스 로드맵

기준 버전: 1.6.0

이 문서는 현재 연결 범위와 다음 구현에서 발급이 필요한 API를 구분한다. 화면에
미연결 자료를 임의 프록시로 채우지 않는다.

## 다음 연결 우선순위

### 1. 한국 반도체 수출과 생산

- 후보 데이터: 반도체 수출액·물량, 메모리 수출, 산업생산, 재고/출하 지수.
- 1순위 공급자: KOSIS 또는 한국은행 ECOS의 공식 시계열.
- 필요한 인증: KOSIS를 선택하면 무료 API 키가 필요하다. 실제 구현 직전에
  테이블 코드와 갱신주기를 확정하고 사용자에게 발급을 요청한다.
- 목적: 미국 거시 레짐과 별도로 국내 반도체 실적 선행환경을 확인한다.

### 2. 국내 반도체 기업 공시

- 후보 데이터: 삼성전자·SK하이닉스 CAPEX, 재고, 부문 매출과 영업이익.
- 공급자: OpenDART 공식 API.
- 필요한 인증: `OPENDART_API_KEY` 신규 발급 필요.
- 주의: 회사별 XBRL 계정 매핑과 연결/별도 재무제표 중복 제거가 먼저다.

### 3. 미국 전력 수요와 발전

- 후보 데이터: 지역별 부하, 발전량·발전원, 설비용량.
- 공급자: EIA Open Data API.
- 필요한 인증: `EIA_API_KEY` 신규 발급 필요.
- 목적: 데이터센터 전력수요와 전력망/발전원 병목을 구분하는 Phase 3 입력이다.

### 4. Server DRAM·HBM·Enterprise SSD

- 필요한 데이터: 계약가격, 출하·재고, bit 공급/수요, HBM 세대별 수급.
- 현재 상태: 신뢰할 수 있는 무료 공식 API가 확인되지 않아 미연결로 유지한다.
- TrendForce 공개 표본은 산업 전체를 대표하지 않으므로 이를 HBM 또는 Server
  DRAM 수치로 재명명하지 않는다.
- 유료 라이선스나 신뢰 가능한 공급자가 정해질 때 별도 source registry와
  라이선스 조건을 검토한다.

### 5. 밸류에이션·이익 추정치

- 후보 데이터: 지수 forward PER, 기업 이익 추정치 revision.
- 현재 상태: 무료 비공식 스크래핑은 안정성과 이용조건 문제가 있어 후순위다.
- 공급자를 선택하기 전 자동 레짐 입력에 넣지 않고, 출처·산식·point-in-time
  제공 여부를 먼저 검증한다.

## API 발급 요청 시점

현재 1.6.0 구현에는 새 키가 필요하지 않다. 다음 작업을 시작할 때는 순서대로
`KOSIS_API_KEY`, `OPENDART_API_KEY`, `EIA_API_KEY`만 요청한다. 유료 산업자료는
제품과 라이선스가 확정되기 전 키나 구독을 요청하지 않는다.
