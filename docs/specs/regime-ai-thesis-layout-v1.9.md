# 투자 레짐 AI 가설 정보구조 v1.9

## 목적

`현재` 화면에서 거시 레짐과 AI 인프라 투자 가설을 구분하되, 기존에 표시하던
데이터를 잃지 않고 점검 순서에 맞게 재배치한다. AI 가설의 여러 축은 하나의
점수나 인과 사슬로 합산하지 않는다.

## 현재 화면 배치

1. **판단 헤더**: 상세점검 필요 여부, AI 가설 읽기 요약, 확정 거시 레짐,
   현재 경제환경과 거시 데이터 품질
2. **현재 점검 항목**: 활성 거시 경보, Snapshot 이후 거시 변화,
   Snapshot 이후 AI 가설축 변화와 데이터 품질 문제
3. **미국 거시경제**: 현재 절대수준과 최근 압력 방향, 상위 기여 지표
4. **AI 인프라 투자 가설**: 아래 여섯 독립축과 상충 신호
5. **금융 전달경로**: 정책 긴축, 장기금리 전달, 신용·금융여건
6. **다음 발표 일정**과 **현재 상태 기록**

### AI 가설의 독립축

| 단계 | 데이터 | 역할 |
| --- | --- | --- |
| 투자 강도 | Microsoft·Alphabet·Meta·Amazon 총 현금 CAPEX | AI 전용 금액이 아닌 투자 프록시 |
| DRAM 핵심축 | 공개 DRAM 가격, 한국 DRAM 수출 | 가격을 주축으로 수출 방향을 확인 |
| 메모리 보조 | 공개 NAND 가격 | DRAM과 분리된 가격 방향 보조 |
| 공급·재고 | KOSIS 생산·출하·재고 | 광의 완제품 재고의 보조 확인 |
| 기업 확인 | 삼성전자·SK하이닉스 매출·CAPEX·재고·영업이익률 | 산업 신호의 기업 공시 확인 |
| 후속 인프라 | EIA 전력판매 | 데이터센터 병목 판정이 아닌 전력 수요 맥락 |

투자·수요 확장과 재고 부담처럼 방향이 충돌하면 상충 신호를 별도 표시한다.
이 요약은 자동 거시 레짐, 상세점검 긴급도 또는 포트폴리오 비중을 직접 바꾸지 않는다.

## 상세 지표 탭

- **거시·시장**: 시장, 성장·고용, 물가, 금리, 유동성·신용
- **AI 투자 가설 / AI 투자**: 하이퍼스케일러 CAPEX만 표시
- **AI 투자 가설 / 메모리·반도체**: DRAM·NAND 가격, 수출,
  생산·출하·재고와 국내 기업 공시
- **AI 투자 가설 / 전력 수요·공급**: EIA 전력판매·발전량·설비용량

## 판정 및 Snapshot 경계

- v1.9의 정보구조 변경은 기존 판정식과 임계값을 바꾸지 않는다.
- 공식 Snapshot은 AI 가설의 각 독립축 상태도 함께 보존한다.
- 이후 같은 축의 상태가 바뀌면 `현재 점검 항목`에 정보성 변화로 표시한다.
- AI 변화는 이번 버전에서 거시 레짐이나 상세점검 긴급도에 합산하지 않는다.

## 화면 검증 기준

- 데스크톱과 390px 모바일에서 가로 스크롤이 없어야 한다.
- 기본 현재 화면에서 9개 관측 범위를 모두 확인할 수 있어야 한다.
- `AI 투자`에 DRAM/NAND 가격 카드가 중복되어서는 안 된다.
- `메모리·반도체`에서 가격, 수요, 공급과 기업 확인을 연속해서 볼 수 있어야 한다.
- 브라우저 콘솔 오류 없이 실제 캐시 데이터로 화면을 직접 확인한다.
