# 투자 레짐 판단 화면 재설계 명세 v0.2

## 목적

이 화면은 지표를 많이 보여주는 대시보드가 아니라 다음 세 판단을 분리해 제공한다.

1. 외부 상세 포트폴리오 점검을 지금 실행해야 하는가.
2. 미국 성장·물가 환경이 어느 방향으로 이동하고 있는가.
3. AI 인프라 투자 가설을 평가할 자동 데이터가 충분한가.

거시 환경 좌표, 자동 레짐, 상세점검 필요도는 서로 다른 상태다. 어느 하나를 다른 상태의 대용으로
사용하지 않는다.

## 재감사에서 확인된 문제

- `중립`은 정상, 상충, 임계 미도달과 데이터 부족을 구분하지 못했다.
- 최근 52개 관측만으로 4분면을 계산해 짧은 표본이 좌표를 과장했다.
- 경보 없음과 환경 정상 상태를 같은 의미로 표현했다.
- 관측일, 수집일, 평가일과 기록일이 구분되지 않았다.
- Snapshot 저장이 외부 상세점검 완료까지 자동으로 의미했다.
- 최신 수정치로 만든 과거 좌표를 당시 알려진 정보처럼 보이게 했다.
- AI CAPEX 데이터가 없는데도 거시 상태와 같은 카드 계층에 배치했다.

## 현재 화면 정보구조

1. 판단 바
   - 상세점검 필요도
   - 자동/후보 거시 레짐
   - 미국 환경 좌표
   - 데이터 품질과 coverage
2. 미국 거시경제 4분면
   - 전체 캐시 시계열 기반 성장·물가 robust z-score 합성
   - 현재/1개월/3개월 궤적
   - 좌표별 confidence
3. 판단 근거와 제한
   - 활성 High/Critical trigger
   - stale/unavailable 데이터
   - 성장·물가 상위 기여 지표
4. 거시 전달경로 모니터
   - 성장, 물가, 금리, 유동성·신용의 방향·근거·신뢰도·활성 경보
5. AI 인프라 투자 가설
   - SEC CAPEX 미연결 상태를 판정 불가로 명시
6. 공식 Snapshot
   - 접힌 보조 기능
   - 평가시각, 좌표 기준일, 관측일 범위, 수집일 표시
   - 외부 상세점검 완료는 명시적 체크박스로만 기록

## 판정 제한

- 현재 FRED 관측값은 최신 수정치다. 1개월/3개월 과거점도 최신 수정치 기준 재구성이다.
- observation date는 발표일이 아니다. 발표 충격의 정확한 당시 판단에는 release/vintage 저장이 필요하다.
- 현재 환경 좌표는 투자 실행 신호가 아니다. 자동 레짐은 신용·시장 충격과 지속조건을 별도로 반영한다.
- 데이터 품질이 `제한` 또는 `판정 불가`이면 경보 부재를 정상 확정으로 표현하지 않는다.

## 수용 기준

- 화면 현재 탭에 `중립`이라는 사용자 상태명이 나오지 않는다.
- 경보가 없고 데이터가 제한된 경우 `정상` 또는 `점검 불필요`로 단정하지 않는다.
- 같은 전체 시계열과 버전은 같은 좌표·기여도·confidence를 반환한다.
- 화면용 이력 길이를 변경해도 4분면 좌표가 달라지지 않는다.
- Snapshot 저장만으로 외부 상세점검 완료 acknowledgment가 생성되지 않는다.
- 과거 좌표와 Snapshot에 최신 수정치 기준이라는 한계를 표시한다.
