# 투자 레짐 의미 체계·희소 데이터 표시 명세 v1.14

> v1.15 확장: 현재 탭은 `지금 할 일·미국 거시·AI 인프라 가설` 3개 상단
> 패널을 사용한다. 가장 가까운 공식 발표를 행동 패널에 표시하고, 자료 품질은
> 독립 판단 카드가 아니라 판정입력·관측일·계산시각 메타데이터 행으로 제공한다.

## 목적

레짐 화면에서 다음 네 종류의 정보를 서로 다른 계층으로 표시한다.

1. 현재 상태: 확정 거시 레짐, 현재 거시 수준, AI 투자 가설
2. 최근 방향: 거시 압력 벡터와 원자료 증감
3. 행동 판단: 상세점검 필요 여부와 활성 위험 신호
4. 자료 운영: 핵심자료 부족, 표시 전용 참고자료의 오래됨, 수집 상태

## 확정 의미

- `automatic_regime`은 성장·물가·금리·유동성 기반의 **확정 거시 레짐**이다.
- `candidate_regime`은 최신 데이터로 즉시 계산한 후보이며 hysteresis 전 값이다.
- AI CAPEX·메모리·전력은 별도 투자 가설 근거이며 거시 레짐에 합산하지 않는다.
- 활성 위험 신호 하나는 상세점검 실행 지시가 아니다. 행동은 `review_urgency`와
  `needs_new_review`로만 결정한다.
- 표시 전용 참고자료의 stale 상태는 사용자나 프로그램의 구현 작업을 지시하지 않는다.

## 침체 교차확인

거시 4분면만으로 침체를 판정하지 않는다. 수익률곡선은 선행축이며 다음 세 동행축을
별도로 확인한다.

- 노동: Sahm·실업률·신규실업수당 경보
- 실질활동: 실질 GDP·산업생산·소매판매의 복수 약화
- 신용: HY/IG OAS와 NFCI 기반 긴축

화면에서는 이를 `현재 경기악화 확인`으로 부른다. 선행 위험만 존재하면
`노동·실물·신용 3축의 악화 확인 없음 · 수익률곡선 선행 경고 관찰`, 현재 악화 영역
한 개면 `노동·실물·신용 중 1개 축 악화 관찰`, 복수 영역이면
`노동·실물·신용 중 복수 축 악화 확인`으로 표시한다.
`동행`, `교차확인` 같은 모델 내부 용어는 사용자 제목과 상태값에 직접 노출하지 않는다.

## 30년물 판정

- 현재 부담: 30Y 실질금리와 30Y-10Y 절대수준을 최근 5회 중 3회 확인
- 최근 추가 충격: 공통 관측일 20관측일 변화의 최근 3회 중 2회 확인
- 두 결과와 관측 기준일을 한 카드 안의 별도 행으로 표시한다.
- 30년물은 10년 실질금리 부담의 제한된 확인축이며 독립 거시영역으로 중복 합산하지 않는다.

## 원시 증감과 의미색

- 시장가격과 원시 금리는 상승·하락 부호만으로 긍정·부정을 정하지 않는다.
- 원시 증감은 중립색을 유지한다.
- 위험회피·시장 스트레스·원화 긴축·실질 할인율 부담처럼 경제적 의미가 규칙으로
  확정된 배지와 복합판정에만 success/warning/danger 색상을 사용한다.
- 보유상품 수익률 색상은 자산 대시보드의 역할이며 레짐 신호와 혼합하지 않는다.
- 백엔드 피드 키와 상태 코드(`events: partial` 등)는 사용자 화면에 직접 노출하지
  않는다. 발표 일정처럼 자체 상태 안내가 있는 원본은 전역 경고에서 중복 표시하지 않는다.
- 향후 발표 일정이 한 건 이상 표시된다면 부분 수집 상태도 별도 경고하지 않는다.
  일정이 전혀 없을 때만 동기화 필요 여부를 빈 상태 문구로 안내한다.
- 자동 판정 미사용 참고자료의 연결 상태는 상단 판단 흐름에 배치하지 않는다.
  현재 상태 기록 아래의 접힌 보조정보에서만 기준일과 출처를 확인할 수 있게 한다.

## 메모리 가격 이력

- DRAM과 NAND를 하나의 정규화 차트에 혼합하지 않는다.
- 관측 1회: 다음 관측 대기
- 관측 2~3회: 첫 관측일·값과 최신 관측일·값을 비교하고 `추세 판단 유보` 표시
- 관측 4회 이상: 제품별 독립 차트, 실제 timestamp 축, 관측점 표시, 선형 연결
- 서로 다른 시작일을 개별 100으로 환산한 뒤 하나의 성과선처럼 비교하지 않는다.
- Contract·Spot·Server RDIMM proxy의 가격 기준과 갱신 주기를 보존한다.

## 하이퍼스케일러 CAPEX 합산

- 4사 합산 CAPEX의 최신 절대액, 직전 분기 대비, 전년 동기 대비를 먼저 표시한다.
- 합산 추이는 독립 선 차트, 기업별 절대액은 독립 그룹 막대 차트로 분리한다.
- 두 차트의 기간과 hover 기준은 동기화하되 이중 Y축은 사용하지 않는다.
- 해당 분기에 Microsoft·Alphabet·Meta·Amazon 자료가 모두 있을 때만 합계를 만든다.
  일부 회사가 비어 있으면 0으로 간주하지 않고 합산 선을 끊는다.
- 백엔드의 동일 분기 합계를 단일 계약으로 사용한다. 현재 화면·지표·Snapshot이
  프론트엔드에서 별도 합산하지 않는다.
- 합계 YoY가 주 판정이고 합산 TTM과 증가 기업 수는 지속성과 확산도의 확인축이다.
- 이 수치는 회사 전체 현금 CAPEX 프록시이며 AI 전용 투자금액으로 부르지 않는다.

## 기준일과 일정

- 핵심 판정일(`decision_as_of`)과 보조자료 관측 범위는 분리한다.
- DRAM 핵심 판정일은 공개 계약가격 표본일이며, 더 늦은 수출·공시일로 덮지 않는다.
- 전력 판정일은 월간 총판매 기준일이고 연간 설비용량은 후행 공급 맥락이다.
- FOMC는 연준 공식 일정, 통계 발표는 FRED 일정을 사용한다. FRED 장애가 발생해도
  연준 공식 일정은 독립적으로 유지한다.
- Headline PCE는 표시용 맥락이고 Core PCE만 물가 결정 입력에 포함한다.

## 후속 데이터

한국 산업생산의 오래된 FRED 표본은 자동 레짐에 사용하지 않고 자료 연결 상태에서
`참고자료 오래됨`으로 표시한다. 공식 KOSIS 산업생산 시계열의 정확한 표 코드와
개정·계절조정 기준을 검증한 뒤 별도 연결한다. 기존 반도체 생산·출하·재고 KOSIS
시계열로 한국 전체 산업생산을 대체하지 않는다.
