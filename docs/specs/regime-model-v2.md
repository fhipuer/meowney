# 거시 레짐 모델 v2

## 목적

상세 포트폴리오 점검 전에 중요한 환경 변화가 있는지를 결정론적으로 알린다. 이 모델은 자산배분 결정을 대신하지 않으며, 동일한 원자료·빈티지·규칙 버전에는 동일한 결과를 반환한다.

## 모델 구조

1. 경제환경: 성장과 물가를 각각 `수준(Level)`과 `모멘텀(Momentum)`으로 분리한다.
2. 전달경로: 현재 금리 제약, 최근 금리 충격, 수익률곡선 선행위험,
   신용·금융여건을 독립적으로 평가한다.
3. 빠른 경보: 임계값을 넘은 충격은 자동 레짐 확정과 별도로 즉시 알린다.
4. 느린 레짐: `유지 / 경계 / 약화 / 전환`은 hysteresis를 적용한다.
5. 행동 판정: `점검 불필요 / 관찰 / 지금 상세 점검`은 자동 레짐과 별도다.

AI CAPEX·반도체·전력 데이터가 연결되기 전 판정 범위는 `macro_only`다. 이 범위에서는 거시 데이터만으로 `전환`을 자동 확정하지 않는다.

## 성장

### 수준

- 실업률 30%
- 신규실업수당 20%
- 월간 비농업 고용 증가분의 3개월 평균 20%
- 실질 GDP 전분기 연율 20%
- 산업생산 YoY 10%

### 모멘텀

고용 클러스터와 실물활동 클러스터를 먼저 각각 합성한 뒤 두 클러스터를 동일 가중한다. 같은 경제정보를 담는 지표 수가 많다는 이유로 기여도가 자동 증가하지 않는다.

- 고용: 실업률 3개월 변화, claims 13주 변화, PAYEMS 월간 증가분 3개월 평균
- 실물활동: 소매판매 3개월 연율, 산업생산 3개월 연율, GDP 전분기 연율

## 물가

### 수준

- Core PCE YoY 35%
- Core CPI YoY 30%
- 임금 YoY 20%
- CPI YoY 10%
- PPI YoY 5%

### 모멘텀

- 기조물가 클러스터: Core CPI·Core PCE 3개월 연율
- 공급 클러스터: CPI·PPI 3개월 연율
- 임금 클러스터: 임금 3개월 연율

`물가 수준 높음 / 모멘텀 완화`처럼 서로 다른 방향을 동시에 보존한다. 모멘텀 완화만으로 물가 수준이 안정됐다고 판정하지 않는다.

## 전달경로

### 정책

`실질 정책금리 = Fed funds - Core PCE YoY`를 표시한다. 이는 간이 ex-post stance이며 r-star 대비 정식 정책갭을 대체하지 않는다.

### 금리 3계층

1. 현재 제약: 실질 정책금리 대용치와 10Y TIPS 절대수준의 큰 값
2. 최근 충격: 공통 관측일 기준 20·63관측일 명목 10Y/TIPS/BEI 변화
3. 침체 선행위험: 10Y-3M 21관측일 평균을 뉴욕 연은 공개 probit 식에 적용

10Y-2Y는 수익률곡선 확인축으로만 쓰고 독립 경보로 중복 합산하지 않는다. 기간
프리미엄은 `THREEFYTP10` 현재 10년 제로쿠폰 추정치로 교체했으며 TIPS와 중복해 점수에
더하지 않는다. 세 계층의 최댓값을 금리 영역 압력으로 사용한다. 상세 산식과 테스트 계약은
[`regime-rates-model-v1.11.md`](regime-rates-model-v1.11.md)를 따른다.

### 신용

HY와 IG는 하나의 spread 클러스터로 취급하고 NFCI는 별도 확인축으로 둔다. 현재 절대수준과 급격한 확대를 모두 평가한다.

## 데이터 품질

화면의 점수는 정확도나 적중확률이 아니다. coverage, freshness, 구성 클러스터의 방향 합치도를 나타내는 `데이터 품질`이다. 모델 적중률은 point-in-time walk-forward 백테스트가 완료되기 전 표시하지 않는다.

## 시점 데이터

`regime_observations`는 최신값 캐시로 유지하고 `regime_observation_vintages`는 append-only 이력으로 사용한다.

- `observation_date`: 값이 설명하는 경제 기간
- `available_from`: 모델이 해당 값 버전을 이용할 수 있게 된 날짜
- `release_date`: 원 기관 발표일(설명·캘린더용)
- `fetched_at`: 앱이 수집한 시각

ALFRED `output_type=4` 초도발표 수집 기반을 구현했다. 완전한 point-in-time 재현에는 수정 빈티지(`output_type=1/2/3`) 백필이 추가로 필요하다. 그 전에는 최신 수정치로 만든 과거 궤적을 표시하지 않는다.

## 현재 환경 시각화 계약

4분면의 점은 성장·물가의 `절대 수준`이다. 최근 모멘텀은 같은 좌표계의 실제 이동량이 아니므로 점에 수치 그대로 더하지 않는다. 화면에서는 방향과 제한된 상대 강도만 가진 `최근 지표 압력` 화살표로 표현한다.

- 점: 현재 성장·물가 절대수준
- 화살표: robust-z 합성 모멘텀의 방향과 범주형 강도
- 화살표 끝: 미래 상태 또는 예측값이 아님
- 과거 궤적: point-in-time 절대수준 좌표가 축적된 뒤 별도 표시
- 침체 판단: 4분면과 분리하여 노동·실질활동·신용의 독립 확인으로 계산

분면명은 `성장 취약/확장 × 물가 안정/압력`의 중립적인 조합만 사용한다. 스태그플레이션·침체·골디락스 같은 해석적 명칭은 추가 조건이 확인될 때만 보조 설명으로 사용한다.

## 검증 원칙과 남은 작업

1. ALFRED 수정 빈티지 백필 및 point-in-time trajectory 복원
2. 실질 민간 국내 최종수요·실질 PCE·trimmed mean PCE 등 독립 데이터 추가
3. 2000년 이후 expanding walk-forward 백테스트
4. benchmark: 기존 규칙, equal-cluster, Sahm-only, yield-curve-only
5. 평가: stress recall, 선행시간, 분기당 오경보, 상태 왕복, Brier/calibration
6. 2020·2021·2022·2023 위기 시나리오 golden fixture
7. 검증 데이터가 충분해질 때만 경험적 모델 확신도를 별도 표시

복잡한 HMM이나 학습 가중치는 challenger로만 운용하며, point-in-time 기준으로 단순 equal-cluster 모델을 실제로 이길 때만 채택한다.
