# DRAM 수출·30년물 장기금리 모델 v1.12

## 목적

이 변경은 서로 다른 두 오판 가능성을 줄인다.

1. 관세청의 DRAM 신고중량을 메모리 bit 출하량으로 오인해 수요 약화로 판정하지 않는다.
2. 10년물만으로는 놓칠 수 있는 30년 장기채 할인율·듀레이션 충격을 별도 확인축으로 감지한다.

두 축 모두 기존 거시 레짐을 임의로 뒤집지 않는다. DRAM은 AI 투자 가설의 수요 확인축이고,
30년물은 기존 금리 영역 안의 제한된 확인축이다.

## 1. DRAM 수출 구조

### 데이터 계약

| 역할 | 관세청 HS 코드 | 사용 방식 |
| --- | --- | --- |
| DRAM 칩 수출 주축 | `8542321010` | 수출액의 구조적 전년비와 단기 순차 변화 |
| MCP 확인축 | `8542323000` | 복합구조칩 수출액의 확장·약화 확인 |
| DRAM 모듈 확인축 | `8473304060` | 칩과 다른 완제품·모듈 단계 수요 확인 |
| 신고중량 | `8542321010` | 포장·패키징 질량 맥락만 표시 |
| 단위중량당 수출액 | DRAM 수출액 / 신고중량 | 가격과 고부가 제품 믹스가 섞인 맥락 지표 |

신고중량은 제품 세대, 적층, 패키징과 단위당 용량이 달라지면 bit 출하와 반대 방향으로
움직일 수 있다. 따라서 신고중량 감소는 상충 신호나 수급 약화 조건이 아니다.

### 시간축

```text
구조적 방향 = 최근 3개월 YoY 평균 + 최근 2개월 YoY 동일 부호 확인
단기 속도 = 최근 3개월 수출액 평균 / 직전 3개월 수출액 평균 - 1
MoM = 최신 월 수출액 / 직전 월 수출액 - 1
```

전년비는 계절성을 줄인 구조 방향이고, 순차 변화는 최근 감속·재가속을 구분하는 보조값이다.
전년비가 높지만 순차 변화가 음수라면 `확장 중 단기 감속`을 함께 보여주되, 즉시 수출 약화로
뒤집지 않는다.

### 결정론적 판정

- `단가·믹스 주도 확장`: DRAM 수출액 3개월 평균 YoY `>=15%`, 최근 2개월 양수이고
  단위중량당 수출액도 같은 조건을 충족.
- `수출액·후공정 동반 확장`: DRAM 수출액이 위 확장 조건을 충족하고 MCP 또는 DRAM 모듈
  수출액도 3개월 평균 YoY `>=15%`, 최근 2개월 양수.
- `수출액 확장`: DRAM 수출액만 확장 조건을 충족.
- `수출 약화`: DRAM 수출액 3개월 평균과 최근 2개월 YoY가 모두 음수이고 단기 순차 변화가
  `<=-10%`이며, 단위중량당 수출액 또는 후공정 확인축도 약화 조건을 충족.
- 그 밖은 `혼조`, 자료가 부족하면 `판정 불가`.

## 2. 30년물 장기 듀레이션 부담

### 데이터 계약

미 재무부 공식 Atom XML에서 명목 금리곡선의 `BC_10YEAR`, `BC_30YEAR`와 실질
금리곡선의 `TC_10YEAR`, `TC_30YEAR`를 수집한다. API 키는 필요하지 않으며 정상 수집 후
8시간 캐시, 실패 후 1시간 재시도를 적용한다.

10Y TIPS는 기존 장기 실질 할인율의 주축을 유지한다. 30Y 명목·실질금리는 `trigger` 역할로,
핵심 거시 데이터 coverage의 분모나 별도 거시 영역에 포함하지 않는다.

### 공통 관측일과 확인 조건

10Y·30Y 명목금리와 10Y·30Y 실질금리가 모두 존재하는 날짜만 정렬해 20·63관측일 변화를
계산한다. 최근 5개 공통 관측일 중 3개 이상에서 아래 두 조건을 동시에 만족해야 한다.

```text
30Y 실질금리 >= 3.00%
30Y 명목금리 - 10Y 명목금리 >= 0.50%p
```

### 점수

| 조건 | 점수 |
| --- | ---: |
| 확인 조건 + 30Y 실질금리 20일 `>=+25bp` | 55 |
| 확인 조건 + 30Y 명목 `>=+35bp` 및 실질 `>=+15bp` | 55 |
| 확인 조건 + 실질 30Y `>=3%`, 실질 변화 `>=+15bp`, 30Y-10Y `>=50bp` | 35 |
| 확인 조건 + 명목 30Y `>=+25bp`, 30Y-10Y `>=50bp` | 25 |

63관측일 명목·실질 30Y가 모두 `>=+20bp`이면 5점을 더하되 최대 60점이다. 원인 표시는
10Y BEI 변화와 함께 `30Y 실질금리 주도`, `인플레이션 기대 동반`, `혼합`으로 구분한다.
30Y 실질금리에는 기대 실질단기금리와 실질 기간 프리미엄이 함께 들어가므로 둘을 직접
분리했다고 주장하지 않는다.

30년물 점수는 기존 최근 금리 충격 점수의 하한으로만 들어가며 하한은 최대 40점이다.
`tightening.long_end_duration`과 기존 `tightening.restrictive_level`은 모두 `rate_level`
근거 클러스터를 사용하므로 독립 High 경보 두 개로 세지 않는다.

## 3. 화면 구성

금리 지표는 다음 순서로 고정한다.

1. 정책금리와 단기금리: Fed, 3M, 2Y
2. 명목 장기금리: 10Y, 30Y
3. 실질금리와 기대인플레이션: 10Y TIPS, 30Y TIPS, 10Y BEI
4. 수익률곡선과 기간 프리미엄: 10Y-3M, 10Y-2Y, Kim-Wright 기간 프리미엄

상단에는 기존 10Y 명목·실질·BEI 구성 차트와 10Y·30Y 명목·실질 비교 차트를 나란히 둔다.
현재 화면의 금융 전달경로에는 30Y 수준, 30Y-10Y, 20관측일 변화와 확인 횟수를 별도 카드로
표시한다.

## 4. 테스트 계약

- 관세청 원자료가 DRAM·MCP·모듈로 중복 없이 집계되는지 검증
- 신고중량 하락만으로 DRAM 상충·약화 신호가 생성되지 않는지 검증
- MCP·모듈의 확장 확인과 구조·순차 시간축 분리 검증
- 미 재무부 XML 필드 매핑, SQLite 캐시와 피드 상태 검증
- 30년물 3-of-5 확인, 25·35·55점 경계, 지속 보강과 40점 하한 상한 검증
- 30년물 자료 부재가 기존 금리 coverage를 낮추지 않는지 검증
- 10Y 제한 수준과 30Y 경보가 같은 근거 클러스터를 사용하는지 검증

## 한계

- MCP와 DRAM 모듈 HS 코드는 HBM 또는 서버용 제품을 직접 분리하지 않는다.
- 관세청 수출액에는 가격, 물량, 환율과 제품 믹스가 함께 들어간다.
- 30년물 경보는 장기채 할인율 부담을 포착하지만 재정 우려와 수급 충격의 인과를 직접
  식별하지 않는다.
- 임계값은 결정론적 운영 규칙이며 point-in-time walk-forward 검증 전까지 통계적 확률이나
  투자수익 보장을 뜻하지 않는다.
