# 계산 안정성 및 성능 개선 스펙

## 계산 계약

- 포트폴리오 합계와 리밸런싱 금액의 기준 통화는 항상 KRW다.
- 티커 자산의 현재 평가액은 `현재 단가 × 수량`이다.
- USD 자산의 원화 평가액은 `USD 평가액 × 현재 USD/KRW 환율`이다.
- USD 자산 원금은 `평균 매수가 × 수량 × 매수 시점 환율`이며 매수 환율이 없으면 현재 환율을 사용한다.
- 티커 없는 수동평가 자산의 `current_value`는 선택한 통화 기준의 **총 평가액**이다.
- USD 현금의 `current_value`는 총 달러 잔액이다. 수량은 다시 곱하지 않는다.
- 현금은 투자손익 계산에서 제외하여 원금을 현재 평가액과 동일하게 본다.
- 중간 계산은 `Decimal`만 사용하고 표시 직전에만 반올림한다.
- 가격을 구할 수 없는 자산은 0원으로 위장하지 않고 `unavailable` 상태로 표시한다.

## 시세 정책

- 정상 시세의 캐시 유효시간은 5분이다.
- 같은 종목에 대한 동시 요청은 하나의 외부 호출로 병합한다.
- 외부 조회 실패 시 마지막 정상 시세를 최대 24시간 사용하고 `stale`로 표시한다.
- 환율은 한 포트폴리오 평가 사이클에서 한 번만 조회한다.

## 일관성 불변조건

- 자산목록 총자산 = 대시보드 총자산 = 리밸런싱 총자산
- 자산별 원화 평가액의 합 = 포트폴리오 총자산
- 총손익 = 총자산 - 총원금
- 동일한 가격·환율 스냅샷에서는 모든 API가 동일한 결과를 반환한다.
- 반환값에 `NaN`, 무한대, 암묵적인 통화 혼합이 존재하지 않는다.

## 성능 목표

- 캐시된 대시보드 핵심 데이터: 1초 이내
- 최초 외부 가격 조회 포함: 3초 이내
- 캐시된 리밸런싱 계산: 1초 이내
- 한 화면 로딩에서 종목당 외부 가격 조회 최대 1회, 환율 조회 최대 1회
